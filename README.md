# codesearch

Это проект про поиск по исходному коду не как по тексту, а как по структуре языка.

Идея такая:
- разбирать код через `ANTLR`
- складывать найденные сущности в `Lucene`
- потом искать не просто строки, а, например, переменные, методы, поля, строковые константы и так далее

Сейчас в репозитории уже есть рабочий Java-прототип. Параллельно есть отдельные наработки для Go и Python, но они сделаны в разных ветках и пока плохо складываются в одну систему.

Эта ветка нужна, чтобы начать собирать всё в более строгий проект.

## Что уже есть

- Java CLI в `app/src/main/java/org/example`
- индексация Java-файлов в Lucene
- поиск по нескольким видам Java-сущностей
- базовые тесты

## Что делаем в этой ветке

План на эту ветку такой:
1. оставить `main` как стабильную стартовую точку
2. описать, во что именно хотим превратить проект
3. постепенно вынести общую логику в нормальный каркас
4. сначала аккуратно встроить Java, потом Go, потом решить, как лучше подтягивать Python
