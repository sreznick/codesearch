# Дорожная карта

## Этап 1. Зафиксировать базу

Сначала просто приводим стартовую точку в порядок.

Что должно получиться:
- отдельная рабочая ветка
- нормальное описание того, что сейчас есть в репозитории
- понятный план, куда вообще двигаемся


Статус:
- сделано

## Этап 2. Ввести общие контракты

На этом этапе нужно договориться с самим проектом, какие у него вообще будут общие сущности.

Что должно получиться:
- базовая общая модель
- интерфейсы, от которых дальше можно строить Java, Go и Python

Что сюда входит:
- определить модель сущностей
- определить модель запросов и результатов
- определить интерфейс языкового модуля

Статус:
- сделано как базовый слой

## Этап 3. Перенести Java в общий каркас

Cначала приводим в новый вид именно её.

Что должно получиться:
- Java остаётся рабочей
- но уже живёт не в старом монолитном CLI, а внутри новой структуры

Что сюда входит:
- отделить CLI от логики
- вынести общие части
- сохранить тесты и поведение

Статус:
- в основном сделано

## Этап 4. Улучшить Java-функциональность


Что должно получиться:
- Java умеет не только искать по имени сущности, но и по типу
- новый CLI покрывает основные сценарии
- результаты выглядят последовательно

Что сюда входит:
- поиск по declared type
- поиск методов по возвращаемому типу
- улучшение CLI
- дополнительные Java-тесты
- выравнивание формата результатов

Статус:
- уже начато

## Этап 5. Довести Java-часть до хорошего состояния


Что должно получиться:
- понятный Java CLI
- тесты на основные сценарии
- чистый путь индексации и поиска
- меньше зависимости от legacy-слоя

Что стоит уметь:
- индексацию проекта
- поиск переменной или поля по имени
- поиск поля или локальной переменной по типу
- поиск метода по возвращаемому типу
- поиск строковой константы
- поиск метода или функции по имени
- показ места в коде, где найдено совпадение
- ограничение выдачи через `--limit`
- фильтр результатов по пути через `--path`

Статус:
- CLI уже умеет основные Java-сценарии
- добавлен отдельный демонстрационный сценарий в `docs/demo.md`
- Java-индексатор перенесен в `org.codesearch.java`
- добавлен поиск методов по return type
